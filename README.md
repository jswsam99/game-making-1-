# 자리 전쟁 2호선

퇴근길 2호선, 강남에서 왕십리까지 14정거장. 승객들이 내리기 전에 보내는 작은 신호를 읽고, 눈치를 견디며 최대한 오래 앉아서 집에 가는 게임입니다.

`index.html` 한 파일로 돌아갑니다. 브라우저로 열면 바로 플레이할 수 있어요. 3D 화면에 쓰는 three.js만 CDN(cdnjs)에서 불러옵니다.

## 플레이 방법

- 좌석 **바로 앞 줄**(또는 문 앞)에 서 있어야 앉을 수 있어요. 한 칸에 한 사람만 설 수 있어요.
- 빈자리가 나면 주변 승객과 경쟁해요. 누가 곧 내릴지 신호를 먼저 읽는 쪽이 이겨요.
- 앉아 있으면 어르신·임산부·아기 엄마가 앞으로 옵니다. 먼저 양보하면 매너 보너스, 버티다 일어나면 감점이에요.
- 착석률 40% / 60% / 75%에 별 하나씩. 별 1개 이상이면 다음 요일이 열립니다.

### 조작

| 키 | 위에서 보기 | 1인칭 |
|---|---|---|
| 방향키 / WASD | 한 칸 이동 | 보는 방향 기준으로 한 칸 이동 |
| Q / E | – | 90° 돌기 |
| 마우스 | 좌석·바닥 클릭으로 이동 | 화면 클릭 후 마우스로 둘러보기, 조준점으로 클릭 |
| Space | 앉기 / 양보 / 일어나기 | 〃 |
| T | 옆 사람에게 말 걸기 (1·2·3으로 선택) | 조준점 앞 사람에게 말 걸기 |
| V | 1인칭으로 전환 | 위에서 보기로 전환 |
| M | – | 미니맵 켜기/끄기 |
| Esc | 일시정지 | 마우스 해제 + 일시정지 |

## 특징

- **월~금 요일별 난이도**: 요일마다 새로운 승객이 등장하고 인파가 늘어납니다.
- **계절과 날씨**: 봄·여름·가을·겨울 복장(여름 반팔, 겨울 롱패딩), 비·눈·미세먼지. 잠실나루~한양대 지상 구간에서는 창밖으로 날씨와 한강(잠실철교)이 보입니다.
- **1인칭 3D 모드**: three.js로 그린 객차 안. 문 위 안내 모니터, 광고판, 노선도, 손잡이, 창밖 터널과 승강장까지.
- **NPC 대화**: 옆 승객에게 말을 걸어 3가지 선택지로 대화. 내리는 역 묻기, 자리 부탁, 핑계 대기, 거짓말까지. 배려석에 앉으면 승객이 먼저 말을 걸어온다.
- **소리**: 브라우저 음성 합성으로 "이번 역은 ○○역입니다. 내리실 문은 오른쪽입니다." 안내, 모터·레일·문 소리.

## 참고

- 역마다 어느 쪽 문이 열리는지는 게임을 위해 정한 값이며, 실제 2호선과 다를 수 있습니다.
- 광고판의 광고는 모두 가상입니다.
- 음성 안내는 기기에 한국어 음성이 있어야 나옵니다.
